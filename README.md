# Supplementary Material

This repository hosts supplementary material for the WellComp 2026 workshop paper:

**Predicting Family Educational Climate from Naturalistic Audio Sensing of Parent-Child Homework Interactions**

The supplementary PDF includes:

- Table S1: Measure overview
- Table S2: Representative administered items
- Table S3: Prediction uncertainty and target correspondence

Only the supplementary material is provided here. The repository does not include participant-level questionnaire data, audio recordings, transcripts, extracted features, or analysis scripts.
